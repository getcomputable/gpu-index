# Security Policy

Report security issues to team@getcomputable.com with "SECURITY" in the
subject. Please do not open public issues for security reports.

We aim to acknowledge reports within 3 business days and to resolve confirmed
vulnerabilities within 14 days.

Scope notes: this repository contains collection and calculation code that
runs against public web pages and public APIs. Reports about data quality
(a wrong price, a broken collector) are welcome as ordinary public issues;
they are not security reports.
